# sing-box 操作手册

本手册面向已安装脚本的 VPS。首次安装与常用快捷命令见 [项目 README](../README.md)，脚本入口为 [`sb.sh`](../sb.sh)。 旧部署升级请先阅读[安全迁移与验收](security-migration.md)。

## 日常管理

在 VPS 上以 root 身份运行 `sing_box` 打开管理菜单。下表中的箭头表示依次输入菜单编号。

| 菜单 | 操作 |
| --- | --- |
| `3 → 4` | 管理出站地址族优先级及 IPv4 / IPv6 源地址 |
| `3 → 11` | 管理 Trojan / Snell |
| `3 → 12` | 管理客户端 WARP 前置（仅 Mihomo 完整订阅） |
| `3 → 10` | 设置自定义域名 HTTPS 订阅 |
| `3 → 8` | 管理订阅入口、令牌和后台端口 |
| `7` | 从已验证的本地发布目录切换管理脚本 |
| `8` | 管理 sing-box 内核版本 |
| `9 → 2` | 刷新并查看 Mihomo / sing-box 客户端配置和订阅链接 |
| `15` | 选择节点公布地址族；设置过出站源地址时重新执行未绑定探测 |
| `17` | 检查和修复脚本依赖及 OpenVZ TUN |
| `0` | 退出主菜单 |

## 状态查看与公网地址刷新

每次进入主界面都会同时向两个 HTTPS 查询站探测公网 IPv4 和 IPv6，取每个地址族先返回的有效结果。设置了出站源地址时，请求绑定该本机地址；否则由系统选择。四个请求并行执行，每个请求最多等待 2.6 秒，为 3 秒内完成刷新留出本地处理时间。主界面分别显示本机已配置的地址数量、所选出站源和公网探测结果。超时或返回无效地址时显示该地址族探测未成功，不使用本机网卡地址或上一次结果替代。公网查询成功不代表节点入站端口已经可达。

每次进入或返回主界面也会并行查询脚本远端版本和内核最新正式版，显示是否有新版本；查询失败时明确提示，不沿用上一次结果。版本查询每个请求最多等待 3 秒，内核主来源失败或未返回有效正式版本时尝试备用来源，两类版本查询合计最多约 6 秒（另有公网地址探测时间）。仅检查版本，不自动升级；更新仍使用菜单 **7** 和 **8**。

自动探测只更新主界面显示，不修改节点配置，也不查询地区或 SOCKS 状态。菜单 **15** 提供 IPv4 / IPv6 配置输出选择：没有源地址设置文件时复用本次未绑定探测结果；存在源地址设置文件时重新执行未绑定探测，避免把指定出站源的结果直接当作节点入站地址。该菜单不会停启 WARP，所选地址族探测失败时保留原节点地址。菜单 **3 → 4 → 4** 可刷新当前出站连通性。菜单 **17** 直接执行缺失依赖的安装及 OpenVZ TUN 设置，耗时取决于软件源。

开启系统级 wgcf / warp-go 时，公网探测可能返回 WARP 出口，不能直接用作 VPS 节点的入站地址。菜单 **15** 检测到这些活动组件时会保留原配置；先关闭全局 WARP，再重新进入主界面并选择配置输出。sing-box 内部的 WireGuard 出站或 SOCKS 模式不受此限制。

## IPv4 / IPv6 代理优先级

进入 **3 → 4 → 1**，可选择 IPv4 优先、IPv6 优先、仅解析 IPv4 或仅解析 IPv6。支持 1.10 系列和新版内核；切换前校验当前内核及附加协议配置，重启失败时恢复原配置。选择会同时保存到新旧内核模板，切换内核后继续生效。

此设置控制 VPS 默认出站访问目标域名时的地址选择。两种优先模式保留 WARP / SOCKS 分流的选族偏好；在 1.10.7，全局选择“仅 IPv4”或“仅 IPv6”也会限制分流域名可用的地址族。它与菜单 **15** 的节点连接地址选择相互独立；以 IP 地址直接路由的请求不受域名解析策略限制。“仅解析”也不等于通过防火墙禁止另一地址族。

优先模式保留另一地址族的候选地址，不保证所有协议和网络故障都能自动回退。切换时会探测所选地址族：优先模式探测失败仍可保存策略；仅解析模式在公网可用性未确认时保留原配置。探测失败不代表 VPS 没有配置该地址族。

## IPv4 / IPv6 出站源地址

进入 **3 → 4 → 2** 选择 IPv4 源地址，或 **3 → 4 → 3** 选择 IPv6 源地址。选择页列出本机地址、网卡、地址状态和有效期；先测试系统自动选择，再对可用候选分别绑定地址查询两个 HTTPS 接口。每个请求连接超时 2 秒、总时限最多 5 秒，最多 4 个请求并发，扫描预算 30 秒；预算耗尽后尚未开始的项目显示未检测。结果分别记录本地源地址、公网回显地址、目标地址和耗时，区分 DNS、绑定、连接、TLS 和超时错误。NAT 环境下本地源地址与公网回显地址可能不同，应选择本机地址。

输入列表序号保存选择，保存前会重新检查地址是否仍然可用，并要求绑定复测成功。输入 **0** 恢复系统自动选择，**r** 重新扫描，**b** 返回。临时地址不推荐用于长期固定出口；尚未就绪、重复检测失败、已弃用、网卡未启用及非全局地址不能选择。

源地址保存在 `/etc/s-box/egress.json`，同步应用到新旧模板及当前配置的原生直连出口。1.10 模板包括 `direct`、`vps-outbound-v4`、`vps-outbound-v6`，新版模板包括 `direct`；带 `detour` 的 WARP / SOCKS 出口不修改。地址族优先级保持独立。配置校验或服务重启失败时，同时恢复配置和地址设置；后续切换内核或重新生成模板会保留选择。

已选地址失效时不会静默切换到其他源地址，可重新进入选择页扫描或恢复系统自动。该功能不修改默认路由、RA、系统 DNS 或节点公布地址。`curl --interface` 不绑定 DNS 请求，系统级 WARP / TUN 路由也不会因此被绕过；HTTPS 探测成功不能替代实际代理 TCP / UDP 连接和公网入站验证。

## 客户端 WARP 前置（单客户端）

进入 **3 → 12**，选择 **1** 启用。脚本为客户端单独申请 WireGuard 参数，将其写入 `/etc/s-box/client_warp.json`（权限 `0600`），并重新生成 `/etc/s-box/clmi.yaml`。在 Clash Verge / Mihomo 中刷新并重载这份完整订阅，关闭旧连接后再验证；客户端无需另外安装 WARP 软件。之后菜单 **9** 刷新、端口/密码/证书调整等生成操作会读取已保存的参数，不重复注册。

开启后的普通代理链路为 `客户端 → WARP → VPS → 目标网站`；Argo/CDN 节点仍保留其中的 CDN/Tunnel 环节。VLESS、VMess、HY2、TUIC、AnyTLS、Trojan、Snell 和各类 Argo 节点均增加前置。自动选择和负载均衡仅选择 VPS 业务节点，不包含裸 WARP 节点。WARP 失败时不会自动改为直连 VPS；局域网和国内网站原有的 `DIRECT` 规则仍使用本地直连。

**此功能只改变客户端到节点的连接，不更改 VPS 的系统路由、WARP 服务或服务端域名分流。** 要让网站看到 VPS 原生出口，先在菜单 **5** 清理对应的 WARP/SOCKS 分流；1.10 内核需要同时清理后缀域名和 geosite 项。系统级 WARP 还需通过菜单 **13** 对应的管理工具取消全局接管。清理这些服务端规则会影响使用相同节点的其他客户端。启用后的出口提示只是分别按服务端 `direct` 源地址进行的 IPv4/IPv6 探测；超时显示未知，不能替代实际代理连接的出口验证。

子菜单 **2** 关闭前置并恢复普通 Mihomo 连接，保留参数以便重新启用。子菜单 **3** 可重新申请或导入参数（同时启用）；**4** 修改 WARP 入口 IP/域名与端口（同时启用）。入口取决于客户端网络，不能用 VPS 上的连通性替代客户端测试。当前只管理一台客户端的配置，请勿将同一套 WireGuard 身份同时用于多台设备或服务端。

自动注册请求连接超时 3 秒、总时限 15 秒，不使用服务端私钥或源码中的共享回退凭据。接口失败可选择 **3 → 2**，导入本机已有 JSON 文件的绝对路径。格式如下，替换所有占位符；地址不带 CIDR 后缀，`ipv6` 可省略，`reserved` 缺省为 `[0,0,0]`，`mtu` 缺省为 `1280`：

```json
{
  "enabled": true,
  "server": "162.159.192.1",
  "port": 2408,
  "ip": "172.16.0.2",
  "ipv6": "<分配的隧道IPv6>",
  "private_key": "<客户端私钥，base64编码32字节>",
  "public_key": "<WARP对端公钥，base64编码32字节>",
  "reserved": [0, 0, 0],
  "mtu": 1280
}
```

参数错误、生成失败或保存中断时保留旧状态及订阅；已开启时凭据丢失不会静默恢复直连，可导入参数或明确选择 **2** 关闭。开关仅提交 `clmi.yaml` 和客户端参数，`sbox.json`、服务端配置、单节点 URI 和二维码不包含此代理链。

回环 HTTP 和域名 HTTPS 从只读发布目录获取三份最新产物。已配置 GitLab 发布的主机可通过 **9 → 2** 同步远程分支。启用客户端 WARP 后，`clmi.yaml` 包含客户端私钥，订阅地址按凭据保管。

验收需在客户端完成：确认 WARP 握手和节点连接可用，再确认网站看到预期的 VPS 原生出口 IP；HY2/TUIC 还需验证 UDP 与实际吞吐。配置校验通过仅证明配置可被 Mihomo 读取，不代表本地网络一定能连接 WARP。

## 更新管理脚本

在受信渠道核对含修复的完整 Git 提交号，按[项目 README](../README.md)提取整份发布树。进入新发布目录，从该目录运行 `bash sb.sh`，选择 **7** 并输入该提交号。已有 VPS 可以保留当前内核和配置。防火墙辅助程序及发布摘要与脚本从同一个目录读取。

## Trojan + TLS 与 Snell（VPS）

新安装会同时配置 Trojan + TLS；使用 sing-box 1.14.0 或更新的正式版内核时，也会配置 Snell。旧安装更新脚本后，进入 **3 → 11「管理 Trojan / Snell」**，可分别启用、设置端口和密码、切换 Trojan 证书或停用协议，无需重装。Trojan 密码和 Snell PSK 在这个菜单中独立管理。

Clash Verge Rev 使用现有的 **`clmi.yaml` Mihomo 订阅**。启用后刷新订阅，两个节点会加入手动选择、自动选择和负载均衡组。Snell 使用 sing-box 服务端 `version: 5`、Mihomo / sing-box 客户端 `version: 4`；sing-box 的这个服务端模式兼容 v4，不启用 v5 的 QUIC 代理模式。客户端需要支持 Snell v4，sing-box 客户端还需要 1.14.0 或更新版本。

Trojan 默认沿用安装时选用的证书，也可在 **3 → 11** 选择已有域名证书。完整订阅会校验证书，sing-box 自签模式内嵌公证书，Mihomo 使用证书指纹。自有域名的 SNI 应与证书 SAN 一致。Trojan 和 Snell 均需放行对应的 TCP 端口。

使用受信域名证书时，Trojan 分享链接会加入 `jhsub.txt`。自签 Trojan、TUIC、AnyTLS 通过完整订阅分发，Snell 也使用完整配置。自签 Hysteria2 URI 带证书 SHA-256，导入后仍要求系统信任的客户端需要安装本实例公证书。 [Hysteria 2 的 TLS 配置](https://v2.hysteria.network/docs/advanced/Full-Client-Config/#tls)

额外入站保存在 `/etc/s-box/sb_extra.json`，服务与原有 `sb.json` 一起加载。设置新协议前会校验合并配置，失败时保留原配置；内核切换也会先用候选内核检查配置，不兼容时保留当前内核。原有五类协议仍使用原管理菜单。

## 自定义域名 HTTPS 订阅（VPS）

运行 `sing_box`，进入 **3 → 10「设置自定义域名分发」**，可直接启用或更换域名；**3 → 8** 用于管理订阅入口。域名订阅由 Caddy 从只读快照直接提供 HTTPS；节点协议及其端口沿用原配置。

### 启用域名订阅

1. 准备独立的订阅域名，例如 `sub.example.com`。将其 A/AAAA 记录指向当前 VPS；初次配置使用 DNS-only（仅 DNS 解析），并确保填写的 IPv4/IPv6 地址可达。
2. 放行 VPS 防火墙与云平台安全组的 **TCP 80、443**。Caddy 直接读取发布目录。
3. 在 `sing_box` 的 **3 → 10** 中输入域名（原 **3 → 8 → 5** 入口仍可用），仅填 `sub.example.com`，不带 `https://`、端口或路径。
4. 输入至少 **16 个字符**的订阅令牌，只能使用字母、数字、`_`、`-`。直接回车会通过 `openssl rand -hex 24` 生成令牌，即 24 个随机字节编码为 48 个十六进制字符。
5. 脚本通过 HTTPS 下载三份订阅，各自与本机原文逐字节比对，再提交入口。

已有系统 Caddy 时使用独立的站点 `import`。脚本自管的 Caddy 使用受审清单固定的官方归档。缺少摘要、下载损坏或配置校验失败时，应先修复对应环节再重试。

三个订阅地址分别为：

```text
https://sub.example.com/<token>/sbox.json
https://sub.example.com/<token>/clmi.yaml
https://sub.example.com/<token>/jhsub.txt
```

`sbox.json` 用于 Sing-box 客户端，`clmi.yaml` 用于 Clash/Mihomo，`jhsub.txt` 为聚合节点。将 `<token>` 换成设置的令牌，或直接复制脚本显示的完整地址。持有链接即可下载订阅内容，请按凭据保管；泄露后通过菜单 **3 → 8 → 2** 轮换令牌，并更新客户端中的链接。

### 日常操作

| 菜单 | 操作 |
| --- | --- |
| `3 → 10`（或 `3 → 8 → 5`） | 启用域名订阅或更换域名 |
| `3 → 8 → 2` | 轮换订阅令牌，回车随机生成 |
| `3 → 8 → 3` | 更换仅本机 HTTP 入口的端口 |
| `3 → 8 → 6` | 显示当前订阅链接及二维码 |
| `3 → 8 → 4` | 停用并卸载订阅入口，保留 GitLab 配置 |
| `9 → 2` | 刷新节点和订阅文件，显示当前域名订阅链接 |

刷新时保留现有文件格式，并逐个文件原子替换；生成或校验失败会保留原订阅文件。客户端需要手动刷新或按自身设置定时刷新订阅，服务端更新文件不会主动推送到客户端。

**9 → 2** 会刷新订阅，并在配置了独立 GitLab 发布令牌时推送。**3 → 7 → 2** 可单独触发发布。客户端和 Telegram 使用域名 HTTPS 链接；原来的 GitLab 写令牌链接应按迁移步骤撤销。

**3 → 8 → 1** 创建仅绑定 `127.0.0.1` 的本地 HTTP 入口，可用于 SSH 转发。旧公网 HTTP 迁移时直接进入 **3 → 10**，提供新令牌，等待三份文件全部通过 HTTPS 字节校验后，脚本才关闭旧监听。

### 与现有网站共用 VPS

脚本自行管理的 Caddy 仅启用 HTTP/1.1、HTTP/2，避免占用 UDP 443。若系统已有 `/etc/caddy/Caddyfile` 且能运行 `caddy` 命令，脚本会加入一条带 `# s-box subscription` 标记的独立订阅配置 `import`，共享现有 Caddy。多用户主机须先关闭管理 API，或将管理端点置于 Caddy 有效 UID 独占的 0700 目录内。脚本校验后通过服务管理器重启共享 Caddy，现有网站连接可能短暂中断。 共享服务使用自定义用户且无法自动识别读取组时，可在核对进程身份后设置 `SBOX_CADDY_GROUP`。

若 TCP 80/443 被 Nginx、非标准安装的 Caddy 或其他入口占用，且脚本无法接入标准 Caddy 配置，脚本会报告冲突。需要在现有站点服务中自行接入订阅路由，或先调整入口配置；脚本不会停止这些服务来抢占端口。

## 更新客户端订阅

1. 在 VPS 运行 `sing_box`，选择 **9 → 2** 重新生成客户端配置和订阅文件。
2. 在客户端刷新订阅并重新应用配置；使用文件导入时，需要重新导入生成的文件。仅更新 VPS 脚本不会更新客户端已有配置。
3. 若客户端设置了 DNS、规则等覆写，核对最终生效配置。订阅原文不一定等于客户端最终使用的配置。
4. 轮换订阅令牌或更换订阅域名后，更新客户端保存的订阅地址。

### 客户端地域规则与本地面板

VPS 和 Serv00 的完整 sing-box 订阅默认从 jsDelivr 获取 MetaCubeX/meta-rules-dat 的 `sing` 分支。客户端首次获取规则，随后按 `update_interval: 1d` 检查。成功载入新规则后，匹配中国域名或 IP 的直连范围会变化。匹配中国域名的 DNS 请求也会改走配置的国内解析器。Serv00 另用境外域名规则选择代理。上游发布规则可以改变已有订阅的这些行为，客户端无需重新向 VPS 拉取配置。

需要审查直连范围时，先核对该仓库一个完整提交中对应的 SRS 文件。VPS 将其 40 位小写提交号单独一行写入 `/etc/s-box/client-rules-revision`，执行 **9 → 2**。Serv00 设置 `SERV00_CLIENT_RULES_REVISION` 并执行 `~/bin/sb --refresh`。核实新 `sbox.json` 的每条地域规则 URL 都含选定提交号，再让客户端刷新。后续升级重新审查、显式更换该值。Mihomo 使用设备上的 GeoIP 数据，VPS 还使用 GeoSite 分流和 DNS 策略。上述提交号作用于 sing-box 的 SRS，使用 Mihomo 做同样审计时，还需在设备上固定经核验的地理数据库及其更新设置。

两端生成的 sing-box 订阅默认关闭 Clash API。使用本地面板时，在单台设备的私有覆写中设置 `experimental.clash_api.external_controller` 为 `127.0.0.1:9090`，把该设备独立生成的随机值写入 `secret`。可用 `openssl rand -hex 32` 生成，保存覆写和面板凭据时限制为设备用户可读。重载后检查回环 `/version`，无认证或其他设备的凭据应返回 401，使用本设备 Bearer 密钥应返回 200。客户端曾导入旧订阅时，还需核对合并本地覆写后的实际监听。
